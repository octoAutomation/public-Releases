# Public Releases

Compiled tools we build in-house, released here once they hit a stable version.

Each tool has its own folder with a README describing what it does and a link to its
latest GitHub Release (where the downloadable build lives). The license here at the
repo root (Apache License 2.0) is the default for everything in this repo; a tool's
own folder can carry a different `LICENSE` if that tool ships under different terms —
check the tool's folder before you rely on the top-level one.
